# valerkakvafem — personal site

## Як запустити
1. Розпакуй архів.
2. Відкрий `index.html` у браузері.
3. Для публікації можна завантажити ці файли на GitHub Pages.

## Як додати свої фото
1. Додай зображення у `assets/gallery/`.
2. Запусти `python generate_gallery.py` з кореня проєкту.
3. Онови сайт. Скрипт автоматично оновить `gallery-data.js`.

Фото з папки показуються у рухомому рядку та повній галереї. Завантаження через браузер навмисно відсутнє, тому сайт працює на GitHub Pages без сервера.
