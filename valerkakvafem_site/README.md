# valerkakvafem — personal site

## Як запустити
1. Розпакуй архів.
2. Відкрий `index.html` у браузері.
3. Для публікації можна завантажити ці файли на GitHub Pages.

## Як додати свої фото
Створи/використовуй:
- `assets/gallery/` — VRChat скріншоти
- `assets/avatars/` — картинки аватарів

У `index.html` заміни блоки `.fake-photo` на:
`<img src="assets/gallery/назва.jpg" alt="VRChat photo">`

Так само можна замінити `.fake-avatar` на `<img>`.
